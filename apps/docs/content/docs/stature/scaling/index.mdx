Scaling decides how large a living entity is, how its box is shaped, and which parts of it a scale is allowed to change. These four pages cover the channels a scale can drive, the datapack frames that name a size, the rigs and hurt regions that work on model parts, and the thresholds that turn the tier mechanics on. Start with channels for the vocabulary, then read frames for the file format.

| Page | What it is |
|---|---|
| [Channels](/docs/stature/scaling/channels/) | The 48 built-in channels, their defaults, and what an override means |
| [Frames](/docs/stature/scaling/frames/) | The frame file format, assignments, precedence and worked examples |
| [Parts and regions](/docs/stature/scaling/parts-and-regions/) | Rigs, part factors, first-person arms and hurt regions |
| [Thresholds](/docs/stature/scaling/thresholds/) | The server config file, the M10 channel options and the micro and macro mechanics |
