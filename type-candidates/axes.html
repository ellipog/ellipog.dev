variable-axis studies doto · handjet · sono
04 · blueprint

Doto — the ROND axis. 0 is a square dot (the dot the hairline grid would use); 100 is round (a plotted drawing's pen). Everything between is available, so the dot can be tuned to the page rather than to the face.

05 · element

Handjet — the ELSH axis (element shape, 0–16) and ELGR (element grid, 1–2). Each row is the same headline with a different element: the face is literally built from a repeatable unit, which is this site's design sentence made visible in the letters.

06 · morph

Sono — the MONO axis. The same drawing, from proportional to monospaced. The site's rule ("prose is sans, identifiers are mono") is this one axis, and the boundary is a number: the sentence below stays prose, the identifier stays an identifier, and you choose where the skeleton changes.
